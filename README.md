# Cosentino Nigeria — Fase 1

Entregable offline de investigación comercial para Lagos, Abuja y Port Harcourt.

- `index.html`: market map y entrada principal para Vercel.
- `dashboard_retail.html`: 58 cuentas Retail con filtros y detalle.
- `dashboard_projects.html`: 44 cuentas de Proyectos con filtros y detalle.
- `resumen_ejecutivo_nigeria_fase1.html`: resumen ejecutivo imprimible.
- `data/`: dataset JSON/CSV y notas de consolidación.

Las páginas son standalone: no requieren build, backend, CDN ni variables de entorno. Las ciudades de Fase 2 (Benin City, Kano, Ibadan, Enugu y Onitsha/Awka) quedan fuera de este entregable.
